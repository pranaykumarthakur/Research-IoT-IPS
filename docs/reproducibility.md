# Reproducibility

To reproduce the findings presented in this research:

1. Ensure Python is installed along with the dependencies listed in `requirements.txt`.
2. Ensure `RT_IoT2022.csv` is correctly placed in `data/raw/`.
3. Open and run the official notebook: `notebook/final_60_20_20_DA_AMS.ipynb`.
4. Execution of the notebook will sequentially produce the same data splits, candidate evaluations, Deployment Scores, and final model selections as reported in the final study.
